# Java 17 Swing Quiz Application

A complete, production-grade Quiz Application built using pure **Java 17 Swing/AWT** and **MySQL 8** connected via **JDBC**.

## Tech Stack
- **Java**: Java 17+ (Swing & AWT only)
- **Database**: MySQL 8.0+
- **Driver**: MySQL Connector/J 8.x
- **Architecture**: MVC Pattern (Model-View-Controller) with DAO layer
- **Security**: SHA-256 password hashing, PreparedStatements for SQL injection prevention

## Quick Start

### 1. Database Setup
1. Start your local MySQL server.
2. Run `database/schema.sql` in MySQL Workbench or CLI:
   ```bash
   mysql -u root -p < database/schema.sql
   ```
3. Verify or change your MySQL password in `src/db/DBConnection.java`.

### 2. Default Login Credentials
- **Admin**: `admin` / `admin123`
- **Student**: `john_doe` / `student123`
- **Student**: `sarah_dev` / `student123`

### 3. Running the Project
#### Option A: IntelliJ IDEA / Eclipse / VS Code
- Open this folder in your IDE.
- Add `mysql-connector-j-8.x.jar` to project dependencies / libraries.
- Run `src/Main.java`.

#### Option B: Terminal / Command Line
```bash
# Linux/macOS:
./run.sh

# Windows:
run.bat
```

## Features
- **Authentication**: Role-based Login & Register (Admin & Student) with SHA-256.
- **Student Portal**:
  - Category selection (Java, DBMS, Aptitude, etc.)
  - Timed 30-second per question quiz engine with instant countdown
  - Automatic answer tracking and auto-submit on timeout
  - Real-time score calculation and permanent database storage
  - Attempt history JTable and Top 10 Leaderboard
- **Admin Portal**:
  - Full Question CRUD (Create, Read, Update, Delete) with interactive JTable
  - Category creation
  - System-wide student scores overview
